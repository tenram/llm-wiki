## Overview

`BehiSecc/awesome-claude-skills` is a curated GitHub list of Claude Skills, organized as a discovery resource for developers and researchers looking to extend Claude's capabilities without building skills from scratch.

## Structure

Skills are grouped into 13 categories: Document Skills (Word/PDF/PPTX/XLSX), Development & Code Tools (30+ entries covering web dev, testing, git, infra), Data & Analysis, Scientific & Research Tools, Writing & Research, Learning & Knowledge (wiki builders, knowledge graphs, document linking), Media & Content, Health & Life Sciences, Collaboration & Project Management, Security & Web Testing, Utility & Automation, Collections (pre-assembled bundles across 50+ domains), and Articles & Research.

## Notable Entries

**VibeSec-Skill** is highlighted as the security-focused recommendation, aimed at helping secure web applications built with Claude. The list also surfaces larger third-party aggregations: **Agent Almanac** (317 skills across 50+ domains) and **agentskill.sh** (69,000+ searchable skills), indicating the third-party skill ecosystem has scaled well past what any single curated list can cover directly.
