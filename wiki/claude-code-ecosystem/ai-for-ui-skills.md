> Sources: Emil Kowalski / AI for UI, 2026-11-15

## Overview

AI for UI is a catalog of 19 skills for building and reviewing interfaces, organized in the order a designer or engineer might use them: vocabulary and library choice, prototyping and design engineering, motion, performance, edge-case testing, animation review, and whole-app improvement.

## Workflow Shape

The catalog starts with skills that improve problem framing, then moves into implementation and refinement. It includes animation vocabulary, UI-library selection, prototyping, design engineering, choreography, Apple-style motion, gestures, mobile-native polish, animation performance, breaking interfaces with unusual content, and strict review. App-level skills identify where motion belongs, improve existing motion, or remove motion that does not help.

## Practical Takeaway

The collection treats visual quality as a sequence of bounded decisions rather than a single “make it beautiful” prompt. Its strongest complement to [Impeccable](impeccable.md) is the explicit motion vocabulary and review lane; the catalog itself is an index, so implementation details live in the linked skill files.
