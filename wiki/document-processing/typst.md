## Overview

Typst is an open-source typesetting project whose contribution guide emphasizes small, discussed, human-understood changes. The supplied source is contribution documentation rather than a complete product reference, so this article focuses on the project workflow and its explicit stance on AI-generated contributions.

## Contribution model

Contributors are asked to begin with a small issue or discussion, explain technical rationale and user-facing use in the pull request, pass CI, and respond to maintainer review. Good changes are self-contained, minimize interfaces, add tests where appropriate, and document new Rust types and Typst definitions.

## Explicit AI boundary

The guide says contributions implemented by an AI model will not be accepted and asks contributors not to use AI to write pull-request descriptions. This is a project policy in the captured source, not a general statement about Typst's capabilities or the broader open-source ecosystem.
