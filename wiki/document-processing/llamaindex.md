## Overview

The LlamaIndex organization (run-llama) — "the document processing platform for AI." 150 repositories spanning a cloud product line (LlamaParse/Extract via LlamaCloud) and open-source document parsing, agent orchestration, and semantic tooling. Flagship `llama_index` repo has 52.2k stars.

## Open-source projects

- **LiteParse** (12.3k stars, Rust) — fast, helpful, open-source document parser; the local/open counterpart to cloud LlamaParse.
- **LlamaAgents / workflows-py** (449 stars) — event-driven, async-first, step-based control flow for AI applications like agents.
- **semtools** (1.9k stars, Rust) — semantic search and document parsing tools for the command line.
- **LlamaParse SDKs** — Python, TypeScript, Go, Java, C#/.NET, plus a Go CLI, for OCR/document parsing in the cloud.

## Cloud (LlamaParse)

- **Parse** — agentic OCR document parsing.
- **Extract** — structured extraction workflows.
- **LlamaCloud admin APIs** — Python, TypeScript, Java SDKs covering Parse, Extract, Classify, Split, Index.
