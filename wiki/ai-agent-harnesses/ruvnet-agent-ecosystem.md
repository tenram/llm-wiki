## Overview

The requested `ruvnet` source is a GitHub profile, not a single project. Its repository listing highlights a family of agent, orchestration, memory, DevOps, and spatial-intelligence projects. The profile snapshot reports 234 repositories; the listing is therefore a catalog signal, not a technical specification for every project.

## Agent-harness focus

The profile prominently describes `ruflo` as a multi-agent harness with swarm coordination, adaptive memory, self-learning workflows, federation, vector retrieval, and integrations with Claude Code, Codex, and Hermes. The same listing includes agentic DevOps tooling and other repositories tagged for agent orchestration, MCP, autonomous agents, and multi-agent systems.

## Separate project boundary

The profile also features RuView, a Wi-Fi sensing project for spatial intelligence, vital-sign monitoring, and presence detection without video. That project belongs to sensing and privacy-sensitive monitoring rather than agent-harness design. The profile should not be read as evidence that all listed repositories share one architecture.

## Evidence limits

This article is intentionally a profile-level index. Claims about an individual ruvnet repository require a separate ingest of that repository's README, code, license, and current release state.
