## Overview

The pm-execution collection packages product-management workflows such as PRDs, OKRs, roadmaps, prioritization, pre-mortems, sprints, stakeholder maps, user stories, meeting notes, test scenarios, and release notes. GitHub Project Skill applies a similar packaging approach to project-board operations.

## Planning workflows

The collection favors named commands with defined outputs: lean decision-ready PRDs, outcome-focused roadmaps, explicit acceptance criteria, structured retrospectives, and red-team checks for load-bearing assumptions. It also includes meeting and live-event workflows that assign owners and dates to unresolved work.

## GitHub Projects boundary

The Netresearch skill is intended to operate GitHub Projects through a constrained workflow rather than ad-hoc API calls. Its repository documentation separates project discovery, field and view handling, issue or draft-item updates, and validation. Access tokens and write operations remain trust-boundary concerns for any installation.

## Practical takeaway

Project-management skills are most useful when they turn ambiguous coordination work into a fixed input/output contract. They do not replace product judgment; they make decisions, assumptions, and follow-up work easier to inspect.
