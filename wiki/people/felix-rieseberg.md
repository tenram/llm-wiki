## Overview

Felix Rieseberg is a software engineer who works on Claude at Anthropic and has co-maintained Electron since 2016. His personal site describes him as maintaining "too many little open source projects," and his GitHub profile (278 repositories, 6.1k followers) backs that up. His work spans the desktop-app stack — Electron, Notion, Slack, Stripe — and, more recently, AI-adjacent desktop tooling.

## Career

- **Anthropic (2025–now):** works "on whatever allows me to make people productive with AI"; has led engineering for Claude.ai, Cowork, and Code Desktop.
- **Notion (2023–2025):** Notion's desktop apps for Mac and Windows plus the web plumbing underneath.
- **Stripe (2021–2023):** core payments APIs.
- **Slack (2016–2021):** the Slack desktop app for macOS/Windows/Linux; later managing the team.
- **Microsoft (2011–2016):** Windows Phone evangelism, then open source — largely making `npm install` work on Windows (`windows-build-tools`).

## Projects

- **Electron** (2016–now) — co-maintainer of the cross-platform desktop framework (123k stars).
- **Electron Fiddle** (2018–now) — the easiest way to try Electron: small experiments, any version, no setup (7.8k stars).
- **windows95** (2018–now) — the full Windows 95 in an Electron app, emulation by v86 (24.3k stars).
- **macintosh.js** (2020) — Mac OS 8 in Electron pretending to be a 1991 Macintosh Quadra, emulation by Basilisk II (8.5k stars).
- **Clippy** (2025–now) — Clippy from Office 97 running a language model on your own computer (1.4k stars).
- **Language Model Builder** (2026–now) — a free Mac app that explains how language models work, then lets you train a small one yourself.
- **claude-coach** — Claude as an endurance coach for marathons, triathlons, and Ironman events (205 stars).

## Writing

His blog back-catalog (2012–2026) is dominated by Electron and desktop-development practice — debugging native Node.js addons, code-signing Electron apps in CI, debugging native crashes on Windows, "Things people get wrong about Electron," and "A Guide to Electron" — alongside newer posts on ambition with models ("How to be more ambitious: A tutorial for humans with models," Oct 2026) and WebGL/Three.js. The range documents a decade-long focus on making cross-platform desktop software reliable.

## Personal Site as Craft

The felixrieseberg.com landing page is itself a deliberate artifact: an interactive 3D-room experience with a static fallback routed for devices where the interactive version might perform badly. Rieseberg frames personal sites as "some of the last places where the Internet is still creative and fun."
