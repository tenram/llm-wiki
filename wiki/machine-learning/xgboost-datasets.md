> Sources: XGBoosting, 2026-10-05

## Overview

XGBoosting's datasets page is an index of worked XGBoost examples using common academic, benchmark, and Kaggle datasets. It is a navigation catalog, not a dataset repository or a single benchmark study.

## Coverage

The catalog includes tabular examples such as Abalone Age, Adult, Boston Housing, California Housing, Cleveland Heart Disease, Covertype, Diabetes, Glass Identification, Ionosphere, Iris, KDDCup99, Linnerud, Sonar, Wheat Seeds, Wholesale Customers, Wine, and Wisconsin Breast Cancer. It also links Kaggle examples for churn, fraud detection, house prices, house sales, handwritten digits, product classification, and Titanic data.

## Practical Use

The examples provide small, recognizable starting points for comparing preprocessing, objective functions, evaluation metrics, and model settings. Because many are toy or historically used datasets, results should not be treated as production performance or as evidence that XGBoost generalizes to a target domain.
