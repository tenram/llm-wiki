# XGBoost

> Sources: dmlc (Apache-2), 2026-08-24
> Raw: [XGBoost library](../../raw/machine-learning/2026-08-24-xgboost-library.md)

## Overview

Optimized distributed gradient boosting library (parallel tree boosting / GBDT) designed for efficiency, flexibility, and portability. Same code runs from a laptop to Kubernetes, Hadoop, Dask, and Spark at billions-of-examples scale. Apache-2 licensed; originated at University of Washington (Chen & Guestrin, KDD 2016).

## Ecosystem

First-class Python, R, and JVM bindings; Optuna integration for hyperparameter search; extensive docs and release notes. The canonical reference implementation of gradient boosting for tabular problems.
