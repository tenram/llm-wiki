# SQL Fiddle

> Sources: Jonathan Magnan / ZZZ Projects, Unknown date
> Raw: [SQL Fiddle](../../raw/dev-tools/sqlfiddle.md)

## Overview

A free, web-based SQL playground for practicing and sharing queries across seven dialects (SQL Server, SQLite, PostgreSQL, MySQL, MariaDB, Oracle, Oracle PL/SQL), with shareable "fiddle" links commonly used to reproduce SQL questions on sites like Stack Overflow. Optional ChatGPT-based query assistance requires login. Maintained by Jonathan Magnan (ZZZ Projects) as the successor to SQL Fiddle v3.
