## Overview

Build Your Own X is a curated catalog of step-by-step resources for recreating technologies from scratch. It organizes external tutorials by technology area and implementation language rather than providing one implementation or course.

## Catalog Shape

The README groups resources under renderers, AI models, augmented reality, BitTorrent, blockchains, bots, command-line tools, databases, Docker, virtual machines, frontend libraries, games, Git, operating systems, programming languages, regex engines, search engines, shells, template engines, text editors, browsers, web servers, and other categories.

Entries link to books, articles, videos, courses, and repositories, and identify the language where the source does so. The catalog includes both foundational exercises and production-oriented walkthroughs, so quality, maintenance, licensing, and completeness vary by linked source.

## Use And Limits

The project is most useful as a discovery index for implementation-first learning: select a technology, choose a language and depth, then evaluate the linked tutorial independently. It is not a uniform curriculum, benchmark, or guarantee that every linked resource remains current.

The repository is released under CC0 according to its README, with contributions submitted through pull requests or issues.
