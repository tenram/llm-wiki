## Overview

Open Graph is a metadata standard letting any web page become a rich, structured object when shared on social platforms (Facebook being the primary consumer/implementer). Four required `<head>` properties — `og:title`, `og:type`, `og:image`, `og:url` — give platforms a single consistent way to extract titles, descriptions, and images for link previews, replacing a patchwork of prior formats (it builds on RDFa, Dublin Core, and microformats).
