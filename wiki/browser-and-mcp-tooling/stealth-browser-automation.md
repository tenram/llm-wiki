# Stealth Browser Automation

> Sources: `playwright_stealth`, `puppeteer-extra-plugin-stealth`
> Raw: [Stealth Browser Automation](../../raw/browser-and-mcp-tooling/stealth-browser-automation.md)

## Overview

These browser-automation helpers reduce detectable automation fingerprints for Playwright and Puppeteer.

## Use Cases

They fit login, scraping, and QA flows that need to behave more like a human browser session.

Use them only where site rules and policy allow automation.
