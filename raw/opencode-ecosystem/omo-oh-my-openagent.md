# Oh My OpenAgent (OMO)

> Source: https://omo.dev/docs
> Collected: 2026-07-31
> Published: Unknown

Oh My OpenAgent (OMO) is a multi-model agent orchestration harness for OpenCode and OpenAI Codex CLI that coordinates multiple AI agents into a development team, rather than relying on a single model for everything.

## Key features

- **Multi-model orchestration** — routes tasks to different AI models based on task type, avoiding single-provider lock-in
- **Specialized agents** — 11 discipline agents with distinct roles: Sisyphus (orchestrator), Prometheus (planner), Atlas (executor), Oracle (consultant), plus utility agents for search, analysis, and vision
- **Planning/execution split** — Prometheus plans strategically through interviews, then Atlas executes with accumulated learnings
- **Ultrawork mode** — "batteries-included" fully automatic exploration, research, implementation, and verification
- **Hash-anchored edits** — content hashing validates every code edit, improving edit success rates
- **Background parallelism** — research, implementation, and verification can run simultaneously
- **Team Mode** — optional parallel multi-agent coordination with 12 dedicated tools
- **60+ lifecycle hooks** for deep customization

Emphasizes breaking free from single-provider lock-in while maintaining reliability through strict verification and cross-task wisdom accumulation.
