# awesome-opencode

> Source: https://github.com/awesome-opencode/awesome-opencode
> Collected: 2026-07-31
> Published: Unknown

A curated collection of plugins, themes, agents, projects, and resources for Opencode, an AI coding agent for the terminal built by Anomaly.

Categories:
- **Official Repositories** — SDKs in JavaScript/TypeScript, Go, and Python, plus the core Opencode CLI
- **Plugins** — 50+ community-built extensions, including memory systems (Agent Memory, Honcho, Harness Memory), safety tools (CC Safety Net, Envsitter Guard), workflow orchestration (FlowDeck with 25 specialist agents, GoopSpec), authentication providers (Gemini Auth, Antigravity Auth), development tools (devcontainers, direnv, command injection), and integration layers (GitHub releases, payments via Dodo)
- **Themes** — visual customizations
- **Agents** — specialized AI agent implementations
- **Projects** — full applications built on Opencode
- **Resources** — documentation and learning materials

The list emphasizes plugins enabling persistent memory, multi-agent coordination, and context optimization, framed as the key challenges in extended AI coding sessions.
