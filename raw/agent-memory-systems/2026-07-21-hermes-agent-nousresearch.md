# Hermes Agent: Overview

> Source: https://hermes-agent.nousresearch.com/
> Collected: 2026-07-21
> Published: Unknown

## What It Is
Hermes Agent is an open-source, MIT-licensed desktop application developed by Nous Research. Available for macOS, Windows, and Linux, it functions as an AI agent that operates across multiple communication platforms while maintaining persistent memory.

## Core Purpose
The agent is designed to grow with users over time, learning from projects and interactions while remaining consistently available across diverse surfaces—whether desktop, terminal, or messaging platforms.

## Key Capabilities
The platform highlights six primary features:

1. **Multi-Platform Integration**: Operates on "Telegram, Discord, Slack, WhatsApp, Signal, Email, CLI — and a growing list of platforms" with unified memory across all interfaces.

2. **Persistent Memory**: "It learns your projects, auto-generates skills, and never forgets how it solved a problem."

3. **Automation**: Enables "natural-language scheduling for reports, backups, and briefings — running unattended through the gateway."

4. **Task Delegation**: Supports "isolated subagents with their own conversations, terminals, and Python RPC scripts."

5. **Web Capabilities**: Includes "web search, browser automation, vision, image generation, text-to-speech, and multi-model reasoning."

6. **Sandboxed Execution**: Offers "five backends — local, Docker, SSH, Singularity, Modal — with container hardening and namespace isolation."

## Nous Research Connection
Hermes Agent is maintained by Nous Research and integrates with their Nous Portal subscription service, which provides access to 300+ AI models and monthly credits for agent use.
