# SQL Fiddle

> Source: https://sqlfiddle.com/
> Collected: 2026-07-31
> Published: Unknown

SQL Fiddle is an online SQL playground for practicing and sharing SQL across multiple database engines.

## Features

- Support for seven SQL dialects: SQL Server, SQLite, PostgreSQL, MySQL, MariaDB, Oracle, and Oracle PL/SQL
- Real-time query execution with instant results
- Shareable fiddle links for collaboration
- AI-powered assistance via ChatGPT chat and query generation (requires login)
- Fully web-based, no install required

Used as a personal practice sandbox, a collaboration tool, and a common reference format for SQL questions on sites like Stack Overflow. Maintained by Jonathan Magnan (ZZZ Projects) as the successor to SQL Fiddle v3; free and ad-free, with issues/feature requests tracked on GitHub.
