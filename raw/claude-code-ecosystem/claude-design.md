# Get Started with Claude Design

> Source: https://support.claude.com/en/articles/14604416-get-started-with-claude-design
> Collected: 2026-07-11
> Published: Unknown

Claude Design lets users create designs, interactive prototypes, and presentations through conversation with Claude, using a split interface: chat on the left, a live canvas on the right. Integrates with an organization's design system, automatically applying brand colors, typography, and components. Refinement happens via chat instructions, inline comments, or direct canvas editing.

Integrates with Claude Code via a `/design-sync` command; supports export to PDF, PPTX, and HTML, or handoff directly to Claude Code. Projects can be shared with view-only, comment, or edit access levels. Includes built-in accessibility review capabilities.

Status: "now available in beta to Pro, Max, Team, and Enterprise plans" on web and Claude Desktop; counts toward the same usage limits as the rest of Claude.

Getting-started steps: create a project (auto-inherits the org's design system); import a design system from GitHub, design files, or an existing codebase; add context such as screenshots or existing assets; describe the desired output in chat; review the generated canvas; iterate via chat/comments/direct edits; export or share the result.
