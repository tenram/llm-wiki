# UI UX Pro Max Skill

> Source: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
> Collected: 2026-07-11
> Published: Unknown

An open-source AI skill for Claude Code (and other platforms) providing design intelligence for building UI/UX across multiple frameworks. Ships 67 UI styles (Glassmorphism, Neumorphism, Brutalism, Soft UI Evolution, Spatial UI/VisionOS, etc.), 161 color palettes tied to product categories, 57 curated Google Fonts pairings, 25 chart-type recommendations, 99 UX/accessibility guidelines, and 161 industry-specific design reasoning rules. Supports 22+ tech stacks: React, Next.js, Vue, Nuxt, Angular, Laravel, SwiftUI, Jetpack Compose, Flutter, React Native, etc.

Core engine: Python 3.x using BM25 ranking across style/palette/pattern/typography domains. Version 2.0 adds "design system generation": analyzes requirements and outputs a full design system (patterns, style priorities, color moods, typography personality, effects, anti-patterns) tailored to verticals (tech/SaaS, finance, healthcare, e-commerce, services, creative, lifestyle, emerging tech).

Install via Claude Code marketplace or `npm install -g ui-ux-pro-max-cli`, then `uipro init --ai [platform]`; auto-activates on UI/UX requests or via `/ui-ux-pro-max` command. Open-source version covers full UI/UX intelligence; a premium tier adds brand identity, logo design, corporate programs, and asset generation.
