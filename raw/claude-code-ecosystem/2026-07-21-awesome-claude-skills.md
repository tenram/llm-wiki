## Purpose
This GitHub repository curates a comprehensive collection of Claude Skills—specialized tools and extensions that enhance Claude's capabilities across diverse domains. The list serves as a discovery resource for developers, researchers, and professionals seeking to extend Claude's functionality.

## Structure & Organization
The repository organizes skills into 13 primary categories:

1. **Document Skills** — Tools for Word docs, PDFs, presentations, and spreadsheets
2. **Development & Code Tools** — 30+ entries covering web development, testing, git workflows, and infrastructure
3. **Data & Analysis** — CSV analysis, database queries, crypto data, and research tools
4. **Scientific & Research Tools** — Bioinformatics, materials science, and academic research
5. **Writing & Research** — Content creation, family history research, and AI writing detection
6. **Learning & Knowledge** — Wiki builders, knowledge graphs, and document linking
7. **Media & Content** — Video/audio processing, music generation, and transcription
8. **Health & Life Sciences** — Medical analysis, genomics, and wellness tracking
9. **Collaboration & Project Management** — Project tracking, Linear integration, and workflow tools
10. **Security & Web Testing** — Vulnerability scanning, OWASP compliance, and code auditing
11. **Utility & Automation** — File organization, LinkedIn automation, and task scheduling
12. **Collections** — Pre-assembled skill bundles across 50+ domains
13. **Articles & Research** — Academic papers on the agent skills ecosystem

## Notable Highlighted Skills

The repository emphasizes **VibeSec-Skill** as a security-focused recommendation: "a resource designed to help secure web applications built with Claude." This reflects security as a core concern for Claude-assisted development.

Additionally featured are comprehensive collections like **Agent Almanac** (317 skills across 50+ domains) and **agentskill.sh** (69,000+ searchable skills), indicating a thriving ecosystem of third-party extensions.
