# article-writing-skills

> Source: https://github.com/IrtezaAsadRizvi/article-writing-skills
> Collected: 2026-07-11
> Published: Unknown

A collection of writing skills/system prompts for use with LLMs (Claude, ChatGPT, Gemini) intended to help users explore technical topics through the thinking patterns of notable engineers and researchers. Currently contains one skill: an "Andrej Karpathy" skill capturing a "first-principles, code-forward" approach to explaining neural networks and ML systems.

Compatible with Claude Code (via `~/.claude/skills/`), Claude.ai/ChatGPT (as system prompts), or any LLM accepting markdown system prompts. Target audience: engineers drafting technical documentation, researchers writing papers/explainers, students learning complex topics, LLM power users building custom agents, technical writers.

Explicit ethical framing: "The goal is not to produce prose that pretends to be authored by them"; users are cautioned against ghostwriting, impersonation, or publishing AI-assisted content without disclosure. Positioned as thinking-framework tools, not style-mimicry tools.

License: MIT. Format: plain markdown files organized by thinking style. Repo stats at fetch time: 13 stars, 1 fork; one skill currently available, contributions welcomed.
