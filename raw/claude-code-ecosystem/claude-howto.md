# Claude How To

> Source: https://github.com/luongnv89/claude-howto
> Collected: 2026-07-11
> Published: Unknown

A visual, example-driven guide to Claude Code, covering basic concepts through advanced agent usage, with copy-paste-ready templates. Positioned as bridging a gap in official documentation, which the repo argues describes features in isolation without showing how to combine them into full workflows, and lacks a guided learning sequence with production-grade examples.

Content organized into 10 modules: Slash Commands, Memory, Skills, Subagents, MCP Protocol, Hooks (documented across 29 event types), Plugins, Checkpoints, Advanced Features (planning modes, background tasks), CLI Reference. States the complete learning path takes 11-13 hours, while a user can get immediate value in 15 minutes by copying a slash-command template. Includes a self-assessment tool to identify knowledge gaps and personalize the learning path. Templates stated to work with Claude Sonnet 5, Opus 4.8, and Haiku 4.5.
