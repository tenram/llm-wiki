The LlamaIndex organization (run-llama) — the document processing platform for AI. 150 repositories, 4.2k followers.

## Cloud Products (LlamaParse)

- **Parse** — Agentic OCR document parsing
- **Extract** — extraction workflows
- **Platform Documentation** at developers.llamaindex.ai

## Open Source

- **LiteParse** (12.3k stars) — a fast, helpful, and open-source document parser, written in Rust
- **LlamaAgents** (`workflows-py`, 449 stars) — event-driven, async-first, step-based way to control execution flow of AI applications like agents
- **LlamaIndex (Python)** (52.2k stars) — the flagship document processing platform; 8.2k forks
- **semtools** (1.9k stars) — semantic search and document parsing tools for the command line, Rust
- **LlamaParse SDKs** — Python, TypeScript, Go, Java, C#/.NET, CLI (Go), Kotlin (llamacloud-admin variants)

## SDKs for LlamaParse

- `llama-parse-py` — Python SDK for OCR and document parsing in the cloud
- `llama-parse-ts` — TypeScript SDK
- `llama-parse-cli` — CLI (Go)
- `llama-parse-java`, `llama-parse-csharp`, `llama-parse-go` — other language SDKs
- `llamacloud-admin-python`, `llamacloud-admin-typescript`, `llamacloud-admin-java` — LlamaCloud admin API SDKs

## LlamaCloud

LlamaParse and related products are offered via LlamaCloud (the cloud platform). The C# SDK covers Parse, Extract, Classify, Split, Index.
