# Microsoft: Classifying Cybersecurity Incidents with Machine Learning

> Source: https://github.com/pavankethavath/Microsoft-Classifying-Cybersecurity-Incidents-with-ML
> Collected: 2026-10-05
> Published: Unknown

This repository classifies cybersecurity incidents as True Positive, Benign Positive, or False Positive using the Microsoft GUIDE dataset. It presents preprocessing, time-based feature extraction, label encoding, correlation analysis, and class-imbalance handling.

The project compares Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, XGBoost, and LightGBM. It uses SMOTE and class-weight adjustments, RandomizedSearchCV, Macro-F1, precision, recall, and SHAP feature analysis.

The source reports a final XGBoost model without SMOTE and reports Macro-F1 scores of 0.91 on validation and 0.90 on test data. It describes the GUIDE dataset as more than 13 million pieces of evidence and more than one million incidents. These are repository-reported results and dataset descriptions.
