# XGBoost

> Source: https://github.com/dmlc/xgboost
> Collected: 2026-08-24
> Published: Unknown

eXtreme Gradient Boosting — an optimized distributed gradient boosting library designed to be efficient, flexible, and portable. Implements ML algorithms under the Gradient Boosting framework; provides parallel tree boosting (GBDT/GBM) solving many data-science problems fast and accurately. The same code runs on major distributed environments (Kubernetes, Hadoop, SGE, Dask, Spark, PySpark) and can solve problems beyond billions of examples.

- License: Apache-2.
- Origins: research project at University of Washington; reference paper Tianqi Chen and Carlos Guestrin, "XGBoost: A Scalable Tree Boosting System", KDD 2016 (arXiv:1603.02754).
- Ecosystem: Python (PyPI/conda), R (CRAN), JVM, Optuna integration, extensive docs at xgboost.readthedocs.io; OpenSSF Scorecard badged; sponsored by NVIDIA, Intel, Comet, Databento via Open Source Collective.
