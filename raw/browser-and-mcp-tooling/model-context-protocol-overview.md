# What is the Model Context Protocol (MCP)?

> Source: https://modelcontextprotocol.io/introduction
> Collected: 2026-07-11
> Published: Unknown

MCP is an open-source standard for connecting AI applications to external systems: data sources (local files, databases), tools (search engines, calculators), and workflows (specialized prompts), enabling AI applications like Claude or ChatGPT to access information and perform tasks. Analogy used: "MCP is like a USB-C port for AI applications... a standardized way to connect AI applications to external systems."

Example use cases: agents accessing Google Calendar/Notion as a personalized assistant; Claude Code generating a web app from a Figma design; enterprise chatbots connecting to multiple databases for chat-based analysis; AI models designing 3D objects in Blender and printing them.

Stated benefits by audience: developers get reduced development time/complexity when building or integrating AI applications; AI applications/agents get access to an ecosystem of data sources, tools, and apps; end-users get more capable assistants that can access data and take actions on their behalf.

Ecosystem support: named clients/tools include Claude, ChatGPT, Visual Studio Code, Cursor, MCPJam, framed as "build once and integrate everywhere."
