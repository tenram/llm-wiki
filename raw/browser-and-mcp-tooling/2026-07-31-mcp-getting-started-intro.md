# What is the Model Context Protocol (MCP)? (2026-07-28 docs revision)

> Source: https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro
> Collected: 2026-07-31
> Published: 2026-07-28

MCP is an open-source standard for connecting AI applications to external systems: data sources (local files, databases), tools (search engines, calculators), and workflows (specialized prompts) — described with the analogy "MCP is like a USB-C port for AI applications."

## What it enables

- Agents accessing Google Calendar and Notion for a more personalized assistant
- Claude Code generating a web app from a Figma design
- Enterprise chatbots connecting to multiple internal databases for chat-driven analysis
- AI models designing in Blender and printing via a connected 3D printer

## Why it matters, by audience

- **Developers**: less integration time/complexity per AI application or agent
- **AI applications/agents**: access to an ecosystem of data sources, tools, and apps
- **End users**: more capable assistants that can access data and take action

## Ecosystem support

Supported across Claude, ChatGPT, VS Code, Cursor, MCPJam, and other clients/servers — "build once, integrate everywhere." Getting-started paths point to building MCP servers, building MCP clients, building MCP Apps (interactive apps inside AI clients), and a core-concepts/architecture page.
