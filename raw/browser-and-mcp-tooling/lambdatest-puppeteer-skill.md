## Skill Overview

This Puppeteer Automation Skill provides reusable patterns and code templates to automate headless Chrome/Chromium for scraping, end-to-end testing, PDF/screenshot capture, and scripted browser workflows. Key features include launching headless browsers, viewport control, navigation and form interactions, robust wait strategies (waitForSelector, waitForNavigation, waitForFunction, waitForResponse), screenshot and PDF generation, and request interception with response mocking or resource blocking. Typical use cases are web scraping and data extraction, automated login and form submission, CI-friendly E2E tests, visual reporting via screenshots or PDFs, and resilient automation by mocking unstable APIs. Core advantages are precise timing controls for reliable synchronization, network-level control for deterministic tests, lightweight reproducible scripts, and easy integration with CI or cloud testing platforms for scheduled runs and shared capabilities.
