## Popular repositories

### anythingmcp (flagship)
Open-source, self-hosted MCP gateway: turn any REST/OpenAPI, SOAP, GraphQL, OData or SQL API into MCP tools for Claude, ChatGPT & Copilot. 331 connectors incl. SAP S/4HANA & Business One, ERP, e-commerce. TypeScript. AGPL-3.0. 738 stars. 85 forks. 50 issues need help.

### sql-to-mcp
SQL to MCP: connect PostgreSQL, MySQL, SQL Server, Oracle, SAP HANA or MongoDB to Claude & ChatGPT. Read-only, audited, no code. JavaScript.

### openapi-to-mcp
OpenAPI to MCP: turn any OpenAPI/Swagger or REST API into an MCP server for Claude & ChatGPT. Every endpoint a tool, no code. Shell.

### sap-hana-mcp-server
SAP HANA MCP server: Claude & ChatGPT read SAP S/4HANA with SQL, guided by SAP's own data dictionary and CDS views. Read-only. JavaScript.

### sap-mcp-server
SAP MCP server: connect SAP Business One, S/4HANA (Cloud, on-premise via OData or HANA SQL) and Concur to Claude & ChatGPT. JavaScript. AGPL-3.0.

### sap-business-one-mcp-server
SAP Business One MCP server: Claude & ChatGPT read partners, items, orders, invoices, payments and journal entries, and create sales orders. JavaScript. AGPL-3.0.

### erp-mcp-server
ERP MCP server: connect 17 ERPs (SAP, Odoo, JTL-Wawi, Xentral, weclapp, ERPNext…) to Claude & ChatGPT. Self-hosted or cloud. JavaScript. AGPL-3.0.

### ecommerce-mcp-server
E-commerce MCP server: connect Amazon, eBay, WooCommerce, Shopware, Kaufland, OTTO and 7 more to Claude & ChatGPT. JavaScript. AGPL-3.0.

### odata-to-mcp
OData to MCP: turn any OData V2 or V4 service, SAP Gateway included, into MCP tools for Claude & ChatGPT. Reads $metadata, no code. Shell. AGPL-3.0.

### anythingmcp-plugin
AnythingMCP plugin for Cursor and other agent clients: your ERP, accounting, shop, CRM and SQL systems as MCP tools, with skills for cross-system briefings and connecting a system. JavaScript. AGPL-3.0.

### codebound-kit
Test kit for CODEBOUND (Safe Script Sandbox for AI Agents in AnythingMCP), Black Forest Hackathon 2026: mock systems, setup, expected results and an acceptance checker. JavaScript. AGPL-3.0.
