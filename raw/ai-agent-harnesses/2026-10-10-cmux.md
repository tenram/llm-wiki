# cmux

A Ghostty-based macOS terminal with vertical tabs and notifications for AI coding agents.

## Features

- Notification rings and a notification panel show which coding-agent pane needs attention.
- An in-app browser can sit beside the terminal and exposes a scriptable API ported from `agent-browser`.
- Vertical and horizontal tabs show git branch, linked PR status/number, working directory, listening ports, and latest notification text.
- `cmux ssh user@remote` creates a workspace for a remote machine; browser panes route through the remote network.
- `cmux claude-teams` runs Claude Code teammate mode with native splits, sidebar metadata, and notifications.
- Browser import can bring cookies, history, and sessions from Chrome, Firefox, Arc, and other browsers.
- Custom commands launch project-specific actions from the command palette.
- A CLI and socket API create workspaces, split panes, send keystrokes, and automate the browser.
- The native Swift/AppKit application uses libghostty for GPU-accelerated terminal rendering and reads Ghostty configuration.
- cmux is open source and GPL licensed.

## Why cmux?

The project was built for parallel Claude Code and Codex sessions where ordinary terminal tabs and generic macOS notifications did not expose enough context. Its sidebar shows workspace metadata and its notification system accepts terminal sequences such as OSC 9, OSC 99, and OSC 777. The `cmux notify` CLI and agent hooks can trigger notifications for Claude Code, OpenCode, and other agents.

The browser supports accessibility-tree snapshots, element references, clicks, form filling, JavaScript evaluation, and development-server verification. Workspaces, tabs, panes, browser URLs, and input are scriptable through the CLI and Unix socket API.

## Session Restore

cmux restores windows, workspace and pane layout, working directories, best-effort terminal scrollback, and browser URL/history. It does not checkpoint arbitrary live process state. Optional local tmux or zellij owners support live detach/reattach, and supported agent hooks can resume sessions from native session IDs. Imported session files are treated as untrusted: potentially executable commands and sensitive state are held back unless explicitly trusted or approved.

## Platform and Installation

cmux currently supports macOS through a native Swift and AppKit application. Installation is available through a DMG or Homebrew:

```bash
brew tap manaflow-ai/cmux
brew install --cask cmux
```

It works with any command-line agent, including Claude Code, Codex, OpenCode, Gemini CLI, Aider, Goose, Amp, Cline, Cursor Agent, and others. It supports SSH and remote tmux sessions.
