## Purpose

Awesome Hermes Skills is a curated, install-ready directory for the Hermes Agent ecosystem. The fetched README describes the list as covering built-in skills, the optional catalog shipped with Hermes, and community skills, plugins, agent profiles, memory providers, surfaces, and tools.

The directory distinguishes built-in, production, beta, and experimental entries. It recommends starting with Hermes, installing one workflow skill such as `youtube-full`, and then adding a workspace or skill-evolution tool.

## Featured and Catalog Areas

The editorial picks include engineering skills, a Hermes web workspace, SkillClaw, YouTube transcript tooling, and media-detection tooling. The built-in catalog is grouped into areas including Apple, autonomous agents, creative work, DevOps, email, GitHub, media, MLOps, note-taking, productivity, research, smart home, social media, and software development.

The optional catalog is described as 117 skills that ship with the repository but are not active by default. Its categories include autonomous agents, blockchain, communication, creative work, data science, DevOps, finance, gaming, health, MCP, migration, MLOps, payments, productivity, research, security, software development, web development, and other domains.

The community section covers media, research, marketing, development, browser automation, communications, productivity, creative work, DevOps, finance, multi-agent systems, smart home, security, and domain-specific tools. The README includes repository links, maintainers, maturity labels, and installation examples.

## Security Notice

The README warns that skills can execute code, access files, call external services, and handle credentials. It recommends reviewing source, pinning versions where possible, using least-privilege credentials, and testing unfamiliar skills in a sandbox.
