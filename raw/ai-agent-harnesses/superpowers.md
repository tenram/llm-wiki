# Superpowers

> Source: https://github.com/obra/superpowers
> Collected: 2026-07-11
> Published: Unknown

An agentic skills framework and software development methodology for coding agents, built by Jesse Vincent and the Prime Radiant team, MIT licensed. Prevents agents from jumping straight to code: asks clarifying questions about goals, presents design options for validation, produces implementation plans scoped for less-experienced developers, emphasizing TDD, YAGNI, and DRY.

Workflow stages: Brainstorming (Socratic dialogue to refine ideas and validate specs), Git Worktree Management (isolated workspaces with clean test baselines), Planning (breaking work into 2-5 minute tasks with exact file paths and verification steps), Development Execution (subagents dispatched per task with two-stage review: spec compliance then code quality), Test-Driven Development (RED-GREEN-REFACTOR, deleting code written before its tests), Code Review (severity-based issue reporting where critical issues block progress), Branch Finalization (merge, PR, or discard options after test verification).

Skills library: Testing (test-driven-development), Debugging (systematic-debugging with 4-phase root cause analysis; verification-before-completion), Collaboration (brainstorming, writing-plans, executing-plans, dispatching-parallel-agents, requesting-code-review, receiving-code-review, using-git-worktrees, finishing-a-development-branch, subagent-driven-development), Meta (writing-skills, using-superpowers).

Supports Claude Code, Antigravity, Codex App/CLI, Cursor, Factory Droid, GitHub Copilot CLI, Kimi Code, OpenCode, Pi, each with its own install command. Community: Discord server, GitHub issues, release-announcement signup.
