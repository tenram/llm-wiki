# oh-my-claudecode (OMC)

> Source: https://ohmyclaudecode.com/
> Collected: 2026-07-11
> Published: Unknown

A zero-configuration Claude Code plugin marketed as turning Claude Code into a coordinated team of 32 specialized agents. Claimed benefits: shipping features 3-5x faster and 30-50% lower token costs. Stated stats: 36,000+ GitHub stars, 32 specialized agents, 40+ built-in skills, 4.8/5 rating from 35,984 reviews, MIT licensed.

Framed problem: solo Claude Code use leads to sequential execution, spending on the wrong models, and no verification gates. Seven "superpowers": 32 specialists (architect, executor, QA tester, security reviewer, etc.), 3-5x faster shipping via parallel execution, 30-50% cost savings through model routing, zero configuration, teams-first architecture with shared task lists, "Ralph mode" for persistent verification loops, natural-language orchestration with no special syntax.

Four execution modes: Autopilot (default, sequential), Ultrawork (max parallelism, 3-5x faster), Team (N coordinated agents, configurable), Ralph (relentless verification with gates). Agent categories span Analysis, Execution, Research, Frontend/UX, Testing, Code Review (six specialized reviewers), Planning; agents run on Haiku, Sonnet, or Opus.

Install: `/plugin marketplace add https://github.com/Yeachan-Heo/oh-my-claudecode`, `/plugin install oh-my-claudecode`, `/omc-setup`. Cites 100+ published articles from Medium, O'Reilly, Anthropic, TechCrunch, The New Stack. Requires Claude Code CLI and a Claude Max/Pro subscription or API key.
