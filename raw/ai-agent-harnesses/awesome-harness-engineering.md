# Awesome Harness Engineering

> Source: https://github.com/ai-boost/awesome-harness-engineering/blob/main/README.md
> Collected: 2026-07-11
> Published: Unknown

A curated list of resources, patterns, and templates for building reliable AI agent harnesses. Defines "harness engineering" as the discipline of designing the scaffolding around AI agents: context delivery, tool interfaces, planning artifacts, verification loops, memory systems, and sandboxes, that determines success or failure on real tasks. Core claim: the harness, not the model, is the primary performance lever.

Organized into: Foundations (canonical essays from OpenAI, Anthropic, Google, IBM, Martin Fowler, academic sources); Design Primitives by problem area (Agent Loop, Planning and Task Decomposition, Context Delivery and Compaction, Tool Design, Skills and MCP, Permissions and Authorization, Memory and State, Task Runners and Orchestration, Verification and CI Integration, Observability and Tracing, Debugging and Developer Experience, Human in the Loop); Reference Implementations (tutorials, generator frameworks, demo harnesses, adjacent collections); Security, Sandbox and Permissions; Evals and Verification; Templates; Production Infrastructure and Operations; Related Awesome Lists.

Notable featured resources: OpenAI's Codex harness documentation, Anthropic's context engineering and tool design guides, Microsoft's TaskWeaver and LLMLingua, Google's Agent Development Kit, academic papers on planning and multi-agent systems, LangChain and LangGraph.
