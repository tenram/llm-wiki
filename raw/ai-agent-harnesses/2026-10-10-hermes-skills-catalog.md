# Bundled Skills Catalog

Hermes ships with a large built-in skill library copied into `~/.hermes/skills/` on install. Each skill links to a dedicated page with its full definition, setup, and usage.

Hermes also syncs bundled skills on `hermes update`, but the sync manifest respects local deletions and user edits. If a skill listed here is missing from a profile's `~/.hermes/skills/` tree, it is still shipped with Hermes; restore it with `hermes skills reset <name> --restore`.

If a skill is missing from this list but present in the repo, the catalog is regenerated by `website/scripts/generate-skill-docs.py`.

## Catalog Structure

The catalog presents skills in Markdown tables grouped by domains such as Apple, autonomous AI agents, creative work, DevOps, email, media, note-taking, productivity, research, social media, software development, and web tooling. Each row gives the skill name, a short description, and its repository path.

Examples include `apple-notes`, `claude-code`, `codex`, `computer-use`, `hermes-agent`, `opencode`, `google-workspace`, `grounded-citations`, `llm-wiki`, `github`, `requesting-code-review`, and `test-driven-development`.
