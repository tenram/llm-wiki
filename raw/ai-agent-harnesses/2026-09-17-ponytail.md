# Ponytail

> Source: https://github.com/DietrichGebert/ponytail
> Collected: 2026-09-17
> Published: Unknown

Makes your AI agent think like the laziest senior dev in the room. "The best code is the code you never wrote." 141k stars. MIT license. He says nothing. He writes one line. It works.

## Numbers

Measured on real Claude Code sessions editing a real open-source repo (FastAPI + React), against the same agent with no skill. Twelve feature tickets, same agent with and without the skill, n=4, Haiku 4.5.

| Metric | ponytail vs baseline |
|--------|---------------------|
| LOC | **-54%** (up to 94%) |
| tokens | -22% |
| cost | -20% |
| time | -27% |
| safety | 100% (no safety guard dropped) |

ponytail is the only arm that cuts every metric and stays fully safe. Biggest cuts where there is a real over-build trap (date picker 404→23 lines, color picker 287→23, reaching for a native `<input>` instead of a component); near zero on already-minimal code. Earlier single-shot benchmark reported 80-94% less code but was partly a conversational-baseline artifact; the agentic numbers are the corrected version.

## The ladder

Before writing code, the agent stops at the first rung that holds:

```
1. Does this need to exist?   → no: skip it (YAGNI)
2. Already in this codebase?  → reuse it, don't rewrite
3. Stdlib does it?            → use it
4. Native platform feature?   → use it
5. Installed dependency?      → use it
6. One line?                  → one line
7. Only then: the minimum that works
```

The ladder runs *after* understanding the problem, not instead of it. Lazy, not negligent: trust-boundary validation, data-loss handling, security, accessibility are never on the chopping block.

## Intensity levels

- `full` (default) — the ladder enforced
- `lite` — lighter touch
- `ultra` — "for when the codebase has wronged you personally"
- `off` — disabled

Default mode via `PONYTAIL_DEFAULT_MODE` env var or `~/.config/ponytail/config.json`.

## Install (selected platforms)

- **Claude Code**: `/plugin marketplace add DietrichGebert/ponytail` then `/plugin install ponytail@ponytail`
- **Codex**: `codex plugin marketplace add DietrichGebert/ponytail`, `codex plugin add ponytail@ponytail`
- **OpenCode**: `{ "plugin": ["@dietrichgebert/ponytail"] }` in opencode.json
- **Gemini CLI**: `gemini extensions install https://github.com/DietrichGebert/ponytail`
- **Copilot CLI**: `copilot plugin marketplace add ...`, `copilot plugin install ponytail@ponytail`
- **Pi**: `pi install git:github.com/DietrichGebert/ponytail`
- **OpenClaw**: `clawhub install ponytail`
- **Hermes**: `hermes plugins install DietrichGebert/ponytail --enable`
- **Cursor**: `node ponytail/scripts/cursor-hooks.js install`
- **AGENTS.md fallback**: rule-only mode works from a checkout on ~20 agents

While active, the ruleset is injected into every subagent spawned via the Agent tool (scopable via `PONYTAIL_SUBAGENT_MATCHER`).

## Commands

- `/ponytail [lite | full | ultra | off]` — set intensity, or report current level
- `/ponytail-review` — review the current diff for over-engineering, hands back a delete-list
- `/ponytail-audit` — audit the whole repo, not just the diff
- `/ponytail-debt` — harvest `ponytail:` shortcuts deferred into a ledger
- `/ponytail-gain` — show the measured impact scoreboard
- `/ponytail-help` — quick reference

## FAQ
