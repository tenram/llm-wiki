# ECC: The Agent Harness Performance Optimization System

> Source: https://github.com/affaan-m/ecc
> Collected: 2026-07-11
> Published: Unknown

ECC is described as an open-source operating system for AI agent harnesses, optimizing performance across Claude Code, Cursor, OpenCode, Codex, and others. The README reports over 211,000 stars and 32,500 forks on GitHub (note: these figures are unusually high for a niche project and could not be independently verified at time of collection).

Described as "the harness-native operator system for agentic work. Built from real-world multi-harness engineering workflows," going beyond configuration files to provide "a complete system: skills, instincts, memory optimization, continuous learning, security scanning, and research-first development."

Key features: cross-harness compatibility (Codex, Claude Code, Cursor, OpenCode, Gemini, Zed, GitHub Copilot); 66 agents across 12+ language ecosystems; 268+ skills for workflow automation; 84 legacy command shims; multi-language support (TypeScript, Python, Go, Java, Perl, Kotlin, C++, Rust, and more); security-first architecture including AgentShield integration; session management with persistence and memory optimization; claims to be "production-ready," evolved from 10+ months of daily use.

Installation: three paths — plugin installation (recommended for Claude Code), manual installer for fine-grained control, minimal profile for low-context setups. Explicitly warns against stacking installation methods (creates duplicate skills, broken configs).

v2.0.0 adds a control-pane substrate, session adapters, MCP inventory management, orchestrator family tools; claims weekly releases across seven agent harnesses with 230+ contributors. License: MIT; commercial option is an "ECC Pro" GitHub App for private repos; community via GitHub Sponsors and Discord.
