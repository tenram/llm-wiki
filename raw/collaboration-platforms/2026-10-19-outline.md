This is the source code that runs [**Outline**](https://www.getoutline.com) and all the associated services. A hosted version is offered at [getoutline.com](https://www.getoutline.com). Documentation is available in [the guide](https://docs.getoutline.com/s/guide).

If you would like to run your own copy of Outline or contribute to development, this is the source repository.

## Installation

See the [hosting documentation](https://docs.getoutline.com/s/hosting/) for production configuration. Available container images include release and nightly images at Docker Hub.

## Contributing

The project asks contributors not to submit AI-generated pull requests and to discuss proposed changes with the core team through an issue or discussion before opening a pull request. Contribution areas include translation, good-first-issue work, performance, developer experience, documentation, bugs, and quality fixes.

## Development

The repository links to a local-development guide and an architecture document. Development logging is categorized; production logs use JSON. HTTP logging can be enabled with `DEBUG=http`, and broader logging with `DEBUG=*`, category-specific `DEBUG` values, and `LOG_LEVEL`.

## Tests

Critical paths should have coverage, especially API endpoints and authentication. Tests use Vitest. The repository documents `make test`, `make watch`, `yarn test:server`, `yarn test:app`, and targeted Vitest commands.

## Migrations

Sequelize is used for migrations, with commands for creating, applying, and rolling back migrations, including migrations against the test database.
