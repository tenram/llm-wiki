<h1 align="center">Mattermost</h1>

Mattermost is an open core, self-hosted collaboration platform for secure teamwork across the software development lifecycle.

## What it offers

- Chat
- Workflow automation
- Voice calling
- Screen sharing
- AI integration

## Architecture

- Core repo for the platform
- Written in Go and React
- Runs as a single Linux binary
- Relies on PostgreSQL

## Deployment

- Self-hosted on-premises
- Cloud trial available
- Monthly compiled MIT-licensed release
