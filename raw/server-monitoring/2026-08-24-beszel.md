# Beszel

> Source: https://github.com/henrygd/beszel
> Collected: 2026-08-24
> Published: Unknown (v0.18.8, Aug 2026)

Lightweight server monitoring platform with Docker statistics, historical data, and alerts. Friendly web UI, simple configuration, out-of-the-box ready. Automatic backup, multi-user, OAuth authentication, API access. MIT licensed. ~24.6k stars, actively maintained (frequent signed releases).

## Architecture

Two components:
- **Hub**: web application built on PocketBase; dashboard for viewing/managing connected systems. SQLite-backed.
- **Agent**: runs on each monitored system, communicates metrics to the hub. Communication via SSH (hub pulls) or WebSocket (agent dials out); unix socket supported for local agents.

## Features

- Lightweight: smaller and less resource-intensive than leading solutions.
- Docker stats: per-container CPU/memory/network usage history.
- Alerts: configurable for CPU, memory, disk, bandwidth, temperature, fan speed, load average, status.
- Multi-user with admin sharing; OAuth2/OIDC (many providers), password auth can be disabled.
- Automatic backups to disk or S3-compatible storage.

## Supported metrics

CPU (host + containers), memory incl. swap and ZFS ARC, disk usage + I/O (multiple partitions/devices), network usage, load average, temperature sensors, fan speed (Linux hwmon), GPU usage/power draw (Nvidia/AMD/Intel), battery, container status/metrics, S.M.A.R.T. disk health (incl. eMMC wear and mdraid health).

## Deployment

Docker images for hub and agent, plus native single static Go binaries for both with official systemd install scripts (get.beszel.dev). Wide arch support. Agent needs host networking (or equivalent) for accurate host stats; SMART collection needs smartctl privileges (file capabilities or ambient capabilities under hardened systemd units).
