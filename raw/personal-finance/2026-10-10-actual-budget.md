## Getting Started

Actual is a local-first personal finance tool. It is 100% free and open-source, written in NodeJS, it has a synchronization element so that all your changes can move between devices without any heavy lifting.

## Installation

There are four ways to deploy Actual:

1. One-click deployment via [PikaPods](https://www.pikapods.com/pods?run=actual) (~2.00 $/month), recommended for non-technical users.
2. Managed hosting via [Fly.io](https://actualbudget.org/docs/install/fly) (~1.50 $/month).
3. Self-hosting using [a Docker image](https://actualbudget.org/docs/install/docker).
4. Local-only apps downloadable for Windows, Mac, and Linux.

## Code structure

The Actual app is split into a few packages:

- `loot-core` - The core application that runs on any platform.
- `desktop-client` - The desktop UI.
- `desktop-electron` - The desktop app.

Actual is a community-driven product. It documents contribution, feature requests, and internationalization workflows.
