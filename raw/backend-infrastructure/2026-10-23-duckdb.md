## DuckDB

DuckDB is a high-performance analytical database system designed to be fast, reliable, portable, and easy to use. It runs in-process inside an application, so it does not require a separate server or external dependencies. It can read remote files, query other databases, and connect to other DuckDB instances when needed.

DuckDB provides a rich SQL dialect with nested and correlated subqueries, window functions, collations, complex types such as arrays, structs, and maps, and friendly SQL extensions that shorten common queries.

DuckDB is available as a standalone CLI and has clients for Python, R, Java, Rust, Go, Wasm, and other environments. It integrates with tools such as pandas.

## Data Access

DuckDB reads and writes CSV, Parquet, JSON, and Excel files from local storage and remote endpoints including S3, HTTP(S), Azure, and Google Cloud Storage. Files can be queried directly:

```sql
SELECT * FROM 'myfile.csv';
SELECT * FROM 'myfile.parquet';
```

It supports open lakehouse formats including DuckLake, Apache Iceberg, and Delta Lake. DuckLake stores table metadata in a SQL database and provides ACID transactions, snapshots, and time travel without a separate catalog server.

## Database Connections And Extensions

DuckDB can attach to PostgreSQL, MySQL, and SQLite and query, join, or move data across those systems without a separate ETL step. The quack protocol lets DuckDB instances connect to each other over HTTP.

Its modular extension mechanism supports bundled core extensions plus community and third-party extensions installed and loaded at runtime. Extensions can add file formats, connectors, functions, and types.

## Development

Development requires CMake, Python 3, and a C++17 compiler. The repository uses `make` for release builds, `make debug` for non-optimized debug builds, and `make unit` or `make allunit` for tests. Performance benchmarking can be enabled with `BUILD_BENCHMARK=1 BUILD_TPCH=1 make`.

Documentation covers installation, SQL, clients, data import, extensions, building, and contribution.
