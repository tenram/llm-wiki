# DOM Libraries: HyperHTML and Linkedom

> Sources: https://github.com/WebReflection/hyperHTML; https://github.com/WebReflection/linkedom
> Collected: 2026-08-18
> Published: Unknown

`hyperHTML` provides lightweight template-driven DOM updates with DOM binding.

`linkedom` provides a fast, server-side DOM implementation for Node.js and worker-like environments.

Both are useful when tests or agents need browser-like DOM APIs without a full browser.
